# 🌟 Nuestro Universo ❤️

Una experiencia inmersiva y romántica creada con amor para una persona especial. Un viaje visual a través de galaxias, estrellas y partículas, todo acompañado de música y animaciones cautivadoras.

## ✨ Características Principales

### 🎨 Visualización 3D
- **Galaxia Interactiva**: Galaxia dinámica con miles de partículas renderizadas con Three.js
- **Cielo Estrellado**: Miles de estrellas con efecto de parpadeo
- **Nebulosas**: Efectos de nebulosa con degradados de colores cósmicos
- **Efectos de Partículas**: Sistema avanzado de partículas con múltiples efectos

### 💫 Interactividad
- **Navegación por Scroll**: Desplázate por las secciones de la experiencia
- **Navegación por Teclado**: Usa las flechas arriba/abajo para navegar
- **Efectos de Seguimiento de Ratón**: La cámara sigue el movimiento del ratón
- **Control de Música**: Alterna la música con un botón flotante

### 🎭 Efectos Visuales
- **Fuegos Artificiales**: Efectos pirotécnicos personalizados
- **Lluvia de Corazones**: Animaciones de corazones flotantes
- **Confeti**: Efectos de confeti multicolor
- **Estrellas Fugaces**: Estrellas que cruzan la pantalla
- **Luces Neón**: Texto brillante con efecto neón parpadeante

### 🎵 Audio
- **Visualizador de Audio**: Visualización en tiempo real de la música
- **Reactividad a la Música**: La galaxia reacciona al ritmo de la música
- **Control de Volumen**: Ajusta el volumen dinámicamente

### 📱 Responsive
- Diseño completamente responsive
- Funciona en desktop, tablet y móvil
- Adaptación automática a diferentes tamaños de pantalla

## 🎮 Cómo Usar

### 1. **Instalación Rápida**
```bash
# Clona el repositorio
git clone https://github.com/drklion484-ai/index.html.git
cd index.html

# Abre index.html en tu navegador
```

### 2. **Usando un Servidor Local (Recomendado)**
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js
npx http-server

# Con PHP
php -S localhost:8000
```

Luego abre: `http://localhost:8000`

### 3. **Personalización**
Edita los siguientes archivos para personalizar:

- **`index.html`**: Texto y contenido
- **`style.css`**: Colores y estilos
- **`assets/foto.jpg`**: Reemplaza con tu foto
- **`assets/musica.mp3`**: Reemplaza con tu música

## 🎨 Personalización Avanzada

### Cambiar Colores
En `style.css`, modifica las variables CSS:
```css
:root {
  --pink: #ff4da6;
  --purple: #6d5dfc;
  --blue: #38bdf8;
  --gold: #ffd166;
}
```

### Modificar Textos
En `index.html`, edita los textos dentro de cada sección.
